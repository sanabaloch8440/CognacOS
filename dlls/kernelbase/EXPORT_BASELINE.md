# kernelbase.dll export baseline

The export inventory and module-definition file are generated from WinExports data for **10.0.26100.7920 (WinBuild.160101.0800)**, AMD64. Dataset file: `data/exports/nt100_x64_26200/kernelbase.dll.json` in [learn-more/winexports](https://github.com/learn-more/winexports/tree/master/data/exports/nt100_x64_26200). The source records exact export names, ordinals, and forwarder strings. The dataset directory label is `26200`; the binary metadata itself reports build **26100.7920**.

CognacOS emits the same named/ordinal export surface and forwarder strings. Ordinary function bodies are still placeholder stubs and do not imply behavioral compatibility. This reference is pinned to that specific binary version, not every Windows 11 servicing build.
